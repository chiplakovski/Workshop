No server

This page talks to the workshop's database, and there is nothing answering. It is the one screen that cannot fall back to this browser's own storage: an account that exists only in one browser is not access to anything.

Who may sign in is kept in the database, so this screen needs you to be signed in before it will show you anything.

First run

If this workshop has nobody in it yet, make the first administrator here. It works once, on an empty system — after that an administrator adds everybody else, and this form stops working for good.

People

Everybody who can sign in, and how. A person with neither a password nor a PIN has no way in at all — which is how everybody starts.

Add somebody

A new person arrives with no way in. You set their PIN or their password afterwards, from the list above — so there is never a moment where an account exists with a password somebody else chose and nobody changed.

My password

You change your own password by proving you know the current one. Without that, anybody who walks past an unlocked tablet owns the account from then on.
