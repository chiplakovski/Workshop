# Workshop

Внатрешна апликација за водење на фирмата — модул по модул, без надворешни трошоци.

## Концепт

Ова е **прототип на бизнис-систем** за секојдневна работа на фирмата (клиенти,
набавки, проекти, работни налози и слично — модулите се дефинираат и растат
со текот на времето). Прототипот е сличен по идеја на претходната верзија
(Varmak Workshop), но започнува од чиста основа.

## Зошто ваков пристап

Бидејќи целта е апликација што фирмата може да ја користи **без надворешни
трошоци** и без потреба од програмер за да работи секојдневно:

- **Чист HTML/CSS/JS**, без framework и без build алатки — секој модул е
  обичен `.html` фајл што се отвора директно во browser.
- **Без сервер и без база на податоци** — податоците се чуваат локално во
  browser-от (`localStorage`), апликацијата работи и без интернет (освен
  фонтовите при прв load).
- **Нула месечни трошоци** — нема хостинг, нема претплата, нема API клучеви.

Ограничување што треба да се знае: бидејќи податоците живеат само во еден
browser, треба редовен backup/export, а подоцна — кога апликацијата ќе почне
да се користи секојдневно во фирмата — ќе треба вистинска централна база на
податоци (тогаш веќе доаѓа и одреден трошок, но може да остане мал/self-hosted).

## Статус

Само концепт за сега — нема уште код. Модулите (login, hub, клиенти,
проекти, набавки, работни налози, документи, извештаи, итн.) ќе се додаваат
чекор по чекор, откако ќе се потврди насоката со сопственикот на фирмата.
