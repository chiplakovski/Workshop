# Workshop

Внатрешна апликација за водење на фирмата — hosted, со вистинска база на
податоци и бекап за сензитивните информации.

## Концепт

Ова е **бизнис-систем** за секојдневна работа на фирмата (клиенти, набавки,
проекти, работни налози и слично — модулите се дефинираат и растат со текот
на времето). Идејата е слична на претходната верзија (Varmak Workshop), но
сега со вистинска hosted база наместо localStorage, бидејќи ќе се чуваат
сензибилни податоци.

## Архитектура

- **Frontend** — чист HTML/CSS/JS, без framework и без build чекор. Секој
  модул е обичен `.html` фајл.
- **Backend/база** — [Supabase](https://supabase.com) (Postgres база +
  автентикација + автоматски бекап), бесплатен план за старт.
- **Hosting** — [Vercel](https://vercel.com), бесплатен план, автоматски
  deploy на push кон овој repo, на бесплатен субдомен (на пр.
  `workshop.vercel.app`). Домен не е потребен за сега.

Оваа комбинација значи: нема сервер за одржување, нема build процес, а
податоците се во вистинска база со бекап и контрола на пристап
(Row Level Security), не само во browser-от на еден компјутер.

## Прв пат го поставуваш ова?

Види [`SETUP.md`](SETUP.md) — чекор по чекор упатство (Supabase account,
Vercel account, поврзување на клучевите). Тоа треба да се направи еднаш.

## Статус

Основа (Supabase Auth login + профили) е подготвена во код, но чека
Supabase/Vercel клучевите од `SETUP.md` за да заработи. Бизнис модулите
(клиенти, проекти, набавки, работни налози, документи, извештаи, итн.) ќе
се додаваат чекор по чекор откако основата ќе биде поврзана и потврдена.
